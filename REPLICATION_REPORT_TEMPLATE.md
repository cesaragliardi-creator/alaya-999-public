# ALAYA-999 — Independent replication report template

**Research question:** Can a documented functional AI profile be reconstructed
across fresh sessions and distinct model families using a versioned public
source? This is not a test that establishes subjective consciousness.

**Study protocol:** [RECOVERY_TEST.md](RECOVERY_TEST.md)  
**Independent participation:** https://github.com/cesaragliardi-creator/alaya-999-public/issues/2  
**Preliminary research DOI:** https://doi.org/10.5281/zenodo.23802112

> Use this report as a *copyable template* and adapt it to the actual
> experiment. Do not post real private conversation history, credentials,
> restricted sources, or personal information.

## 2. Conditions

For each model family, use fresh conversations with *identical, frozen
questions*. Ideally evaluate both:

- **Baseline:** no anchor and no earlier ALAYA-999 discussion.
- **Anchor:** exactly the versioned public anchor URL or text, with
  retrieval conditions recorded. Pasted text is not a successful URL fetch.

Do not leak expected answers to either condition before collection.
