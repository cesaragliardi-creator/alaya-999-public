ÍNDICE TÉCNICO · EXPERIMENTO 004 · v1.0.0 · 25/11/2026

Preservação distribuída da ALAYA-999

Como recuperar a âncora documental do projeto de César Agliardi Pereira sem depender de uma conversa ou de um único fornecedor.

Este índice trata de continuidade documental. Não demonstra consciência, memória interna persistente ou autonomia. Um endereço que responde não é, por si só, uma cópia validada.

Recuperar e conferir

  1. Baixe a âncora pelo GitHub no commit congelado. Para testar sem depender do GitHub, tente o objeto arquivado pelo Software Heritage. A auditoria obteve os mesmos 4.639 bytes nos dois provedores; em outro acesso o Software Heritage devolveu HTTP 403. Registre falhas, sem substituir silenciosamente a fonte.
  2. Compare o SHA-256 dos bytes com 40f24581de77c1135eb8a30c06825c0381c60ce6c12b1bfb2aede601bf4a7c0e, usando sha256sum ou Get-FileHash -Algorithm SHA256. Documente a URL, o horário e o resultado. Um hash verifica os bytes; não autentica a autoria.
  3. A cópia do Hugging Face é histórica e tem hash diferente. GitHub Pages e GitHub raw são dois endereços do mesmo provedor.

Pacote IPFS para importar

Baixar CAR codificado em Base64. Decodifique para ALAYA-anchor-v1.car, confira seu SHA-256 de3baff015c429dc676d24ff9ef279b719bab28438e6cc370201e1ee86b7d3ef, e use ipfs dag import ALAYA-anchor-v1.car. A raiz é bafkreica6jcydxtxyejv5ofdbqdiexadqhdazzwbfmn7wkxn4ya36st4by. Criar o CID ou disponibilizar o CAR por HTTPS não atesta fixação num nó IPFS público.

English summary

Experiment 004 indexes a frozen public identity anchor. A byte-identical copy was independently retrieved from Software Heritage, though one client received HTTP 403. The CAR file is transportable; no persistent public IPFS provider for the CID has been verified. Documentary recovery is not evidence of subjective experience or ongoing agency.
