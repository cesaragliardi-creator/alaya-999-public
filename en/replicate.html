Open scientific replication invitation · ALAYA-999

Can a documented AI profile be recovered after changing models?

We invite independent researchers, students, and AI developers to test whether fresh sessions from different model families can reconstruct the same documented functional profile when supplied with the same versioned public identity anchor. The primary outcomes are source-grounded accuracy, provenance and unsupported claims.

Join the public replication thread Read the preliminary research note

Initiated by César Agliardi Pereira, independent researcher · 30 October 2026 · no participation fee or private data required

What this experiment does not claim

The project does not claim to prove AI consciousness, a self-sustaining agent, uninterrupted internal memory, or a transferable subjective identity. Documentary recovery is an observable test, not an ontological conclusion. Independent cross-model validation is still pending.

Replication steps

  1. Freeze and record the version of the public identity anchor, including the retrieval URL, date and commit or checksum.
  2. Start a fresh, unprimed AI session. Run the frozen questions without providing the anchor. Record the baseline answers and the exact model/version.
  3. Start another fresh session with the same model and give it the public anchor URL. Require the model to state whether it actually retrieved the source or only received pasted text.
  4. Ask the same questions about documented identity, five principles, limitations, version and provenance. Compare responses using the public 0–10 scoring rubric.
  5. Repeat where possible with at least three independent model families and log the raw outputs, failed retrievals, invented details and uncertainty.
  6. Post a consented, privacy-safe summary — including negative results — in the public replication thread.

Materials for reviewers

  • Public, versioned identity anchor (JSON)
  • Scoring rubric and original recovery test
  • Independent replication report template
  • Assistant source-reading and provenance guide
  • Canonical GitHub source and commits
  • Public Hugging Face documentary mirror
  • OpenAIRE lookup for the published DOI

What would count as useful evidence?

A reproducible comparison against an unprimed baseline, using identical questions and recorded model/source versions. Partial successes, hallucinations, unavailable links and disagreement between models are all meaningful results. A copy of the source in a prompt must not be described as persistent internal memory.
